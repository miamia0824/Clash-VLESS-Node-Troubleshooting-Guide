## 二、Clash Verge Rev 订阅导入教程

1. 下载并安装 Clash Verge Rev。
2. 登录订阅服务网站，复制订阅链接。
3. 打开客户端，进入「订阅」页面。
4. 粘贴订阅链接并导入配置。
5. 进入「代理」页面，选择需要使用的节点。
6. 开启系统代理，测试网络连接是否正常。

日常使用建议根据需求选择规则模式，避免不必要的代理流量消耗。

## 三、如何进行节点延迟检测？

在 Clash Verge Rev 的代理页面中，可以通过延迟测试功能查看各个节点的响应时间。

| 节点延迟 | 参考体验 |
| --- | --- |
| 0–100ms | 响应较快 |
| 100–200ms | 日常使用通常足够 |
| 200–300ms | 可能出现一定延迟 |
| 300ms 以上 | 建议尝试其他节点 |
| Timeout | 测试请求超时 |

需要注意，延迟低并不代表下载速度一定快。节点的实际体验还与带宽、线路质量、运营商及网络拥堵情况有关。

## 四、常见网络故障及解决方法

### 1. 节点全部显示 Timeout

可以按照以下顺序进行排查：

- 检查本地网络是否正常。
- 检查套餐是否到期。
- 确认剩余流量是否充足。
- 更新订阅配置。
- 重启客户端。
- 查看订阅服务商的维护公告。

如果所有节点均无法连接，可能是订阅配置、客户端或服务端出现异常。

### 2. 节点延迟正常，但网页无法打开

可能原因：

- 未开启系统代理。
- 代理规则配置异常。
- DNS 解析失败。
- 浏览器代理设置冲突。
- 目标网站暂时无法访问。

建议检查代理设置，并切换其他节点进行测试。

### 3. 订阅更新失败

- 确认订阅链接是否完整。
- 检查订阅链接是否已经重置。
- 确认账号及套餐状态正常。
- 检查客户端是否支持对应的订阅格式。
- 尝试重新导入订阅。

请勿将自己的订阅链接公开分享，以免造成流量损失或账号安全问题。

### 4. 手机和电脑使用同一节点，延迟却不同

即使连接同一个 Wi-Fi，不同设备的网络表现也可能存在差异。

常见影响因素包括：

- 客户端版本及核心不同。
- 延迟测试地址不同。
- DNS 配置不同。
- 设备无线网络性能不同。
- 后台应用占用网络资源。

建议统一测试地址和测试环境后再进行比较。

### 5. 节点晚上速度变慢

晚间网络使用高峰期可能出现线路拥堵。

可以尝试切换不同地区的节点，或在不同时间段进行测速，判断是否存在高峰期网络波动。

## 五、如何选择合适的节点地区？

| 节点地区 | 参考使用场景 |
| --- | --- |
| 香港 | 日常浏览、低延迟需求 |
| 日本 | 日常网络访问、亚洲地区服务 |
| 新加坡 | 海外办公、资料查询 |
| 美国 | 海外网站、AI 工具 |

不同运营商连接同一地区节点的表现可能不同，建议以实际测试结果为准。

## 六、如何选择订阅节点服务？

选择订阅服务时，建议重点关注以下几个方面：

- 节点连接成功率及稳定性
- 晚间高峰期网络表现
- 套餐价格及流量额度
- 节点地区及协议支持
- 多设备使用限制
- 客户端兼容性
- 售后服务及维护情况

不建议仅凭价格或单次测速结果选择长期套餐，有条件的话可以先进行体验。
